# Triple Espresso

## Descripción del proyecto

Triple Espresso es una página web para una cafetería ubicada en Triple Peaks. El sitio presenta información sobre la cafetería y permite a los usuarios reservar una mesa mediante un formulario.

El proyecto fue desarrollado utilizando HTML y CSS, aplicando conceptos de diseño web, Flexbox, posicionamiento, formularios y metodología BEM para la organización de las clases CSS.

## Funcionalidades

- Navegación mediante enlaces internos.
- Información sobre la cafetería y sus horarios.
- Formulario para reservar una mesa.
- Validación de campos obligatorios en el formulario.
- Enlaces a redes sociales.
- Efectos `:hover` en elementos interactivos.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Metodología BEM
- Git y GitHub
- VS Code
